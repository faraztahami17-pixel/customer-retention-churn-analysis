# customer-retention-churn-analysis
Customer Retention &amp; Churn Analysis (IBM Telco - 7,043 customers)__ — End-to-end SQL + Python + Power BI project. Found __26.54% churn (1,869/7,043)__ with __$139k/month revenue at risk__. Top drivers: __Month-to-month 42.71%__, __0-6 months 52.94%__, __Electronic check 45.29%_ _Fiber 41.89%__. Built a 3-page Power BI dashboard + risk segmentation
